# Backend

FastAPI application that serves the exported Next.js frontend at `/` and owns all `/api` routes. Dependencies are in `pyproject.toml`, locked with `uv`. Tests are in `tests/`.

- `db.py`: `Database` opens `data/board.sqlite3`, creates or migrates the schema (`PRAGMA user_version`, currently 4), and provides `transaction()` (`BEGIN IMMEDIATE`, foreign keys on).
- `users.py`: `UserStore` handles registration, scrypt password hashing, 30-day sessions in the `sessions` table (SHA-256 of the token), password change, account deletion, and admin operations. It seeds the admin `user` / `password` once, when no account has a password. Errors are `UserError` subclasses with HTTP status codes: 401 for bad sign-in, 403 for a wrong password confirmation, 404, 409, 422.
- `board.py`: `BoardStore` handles multiple boards per user, sharing (`share`, `remove_member`, `leave`; roles owner, editor, and viewer, resolved by `_access` and enforced by `_require`; `BoardForbidden` is 403), assignees that must be members, columns (1-12, add/rename/move/delete), and cards with priority, due date, and labels. Every mutation goes through `apply_operations(user_id, board_id, ops, source)` in one transaction and returns the full snapshot. Each `_op_*` returns `(card_id, summary)`, which `_log` writes to `activity`; sharing changes and comments are logged too. Checklist items are changed through the `add_checklist_item`, `edit_checklist_item`, and `delete_checklist_item` operations (also available to the AI) and appear in each card's `checklist`. `comments`, `add_comment`, `delete_comment`, and `activity` serve the comment and history routes; `my_work` lists open cards assigned to a user across boards. Archived cards (`archived_at` set) are skipped by `_card` (unless `archived=True` or `None`), `_card_ids`, and snapshots; `_op_archive_card`, `_op_restore_card`, and `archived` handle the archive.
- `ai.py`: per-board chat. Strict Pydantic operations (`add_column`, `rename_column`, `move_column`, `add_card`, `edit_card`, `delete_card`, `move_card`) are applied atomically. Viewers get a read-only prompt and a 403 if the model still returns operations.
- `openrouter.py`: httpx client for `openai/gpt-oss-120b` with an injectable transport.
- `main.py`: `create_app(frontend_dir, data_dir)` plus `default_app()`, the uvicorn `--factory` entry point. Importing the module touches no data. `PM_FRONTEND_DIR` and `PM_DATA_DIR` override the default paths. Dependencies: `User`, `Admin` (403 for non-admins), `AIUser` (10 AI requests per user per minute).

Tests share an `app` fixture (`tests/conftest.py`) and helpers (`tests/helpers.py`: `client_for(app, username)`, `first_board`, `add_card`, `card_id`). Coverage must stay at or above 80% (currently about 99%). Live OpenRouter tests run only with `OPENROUTER_LIVE_TEST=1` and a key. API and schema details are in `../docs/BOARD_MODEL.md` and `../docs/AI_CONTRACT.md`.
